### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 08` | `%` — символ главного кадра и начала УП. 08 — номер УП |
| `T5 M6` | Вызов фрезы Ø10 мм из 5-го гнезда инструментального магазина. M6 — автоматическая смена инструмента |
| `G90 G17` | Абсолютная система координат. Плоскость круговой интерполяции — XY |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G42 D1` | Включение коррекции на радиус; инструмент справа от контура по направлению движения. В корректоре D1 задан радиус фрезы 5 мм |
| `G0 X69.7 Y89 Z44` | Перемещение на ускоренной подаче в т. 1 |
| `S4777` | Установка рабочей частоты вращения шпинделя n = 4777 об/мин |
| `Z7.3` | Перемещение на ускоренной подаче в т. 2; действует G0 |
| `G1 G94 Y32.8 F239 M8` | Перемещение на рабочей подаче в т. 3. Включение подачи охлаждения. Минутная подача — 239 мм/мин |
| `G2 X53.3 Y16.4 R16.4` | Перемещение по дуге по часовой стрелке в т. 4. Радиус — 16,4 мм |
| `G1 X41.41` | Перемещение на рабочей подаче в т. 5 |
| `G2 X36.56 Y20.5 R4.92` | Перемещение по дуге по часовой стрелке в т. 6. Радиус — 4,92 мм |
| `G3 X16.4 Y41.34 R24.6` | Перемещение по дуге против часовой стрелки в т. 7. Радиус — 24,6 мм |
| `G2 X12.3 Y36.49 R4.92` | Перемещение по дуге по часовой стрелке в т. 8. Радиус — 4,92 мм |
| `G1 Y89` | Перемещение на рабочей подаче в т. 9 |
| `G0 Z44 M9` | Перемещение на ускоренной подаче в т. 10. Отключение подачи охлаждения |
| `G40` | Отключение коррекции на радиус |
| `X50 Y200 Z150` | Перемещение на ускоренной подаче в т. 0; действует G0 |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |
