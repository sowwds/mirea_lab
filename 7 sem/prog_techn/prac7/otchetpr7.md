### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 07` | `%` — символ главного кадра и начала УП. 07 — номер УП |
| `T4 M6` | Вызов фрезы Ø20 мм из 4-го гнезда инструментального магазина. M6 — автоматическая смена инструмента |
| `G90 G17` | Абсолютная система координат. Плоскость круговой интерполяции — XY |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G41 D1` | Включение коррекции на радиус; инструмент слева от контура по направлению движения. В корректоре D1 задан радиус фрезы 10 мм |
| `G0 X-15 Y-38.25 Z76` | Перемещение на ускоренной подаче в т. 1 |
| `S4777` | Установка рабочей частоты вращения шпинделя n = 4777 об/мин |
| `Z33` | Перемещение на ускоренной подаче в т. 2; действует G0 |
| `G1 G94 X12.75 F430 M8` | Перемещение на рабочей подаче в т. 3. Включение подачи охлаждения. Минутная подача — 430 мм/мин |
| `G3 X38.25 Y-12.75 I0 J25.5` | Перемещение по дуге против часовой стрелки в т. 4. Центр дуги — (12,75; −12,75), радиус — 25,5 мм |
| `G1 X63.75` | Перемещение на рабочей подаче в т. 5 |
| `G2 X89.25 Y-38.25 I0 J-25.5` | Перемещение по дуге по часовой стрелке в т. 6. Центр дуги — (63,75; −38,25), радиус — 25,5 мм |
| `G1 Y-63.75` | Перемещение на рабочей подаче в т. 7 |
| `G3 X63.75 Y-89.25 I0 J-25.5` | Перемещение по дуге против часовой стрелки в т. 8. Центр дуги — (89,25; −89,25), радиус — 25,5 мм |
| `G1 X38.25` | Перемещение на рабочей подаче в т. 9 |
| `G2 X12.75 Y-63.75 I0 J25.5` | Перемещение по дуге по часовой стрелке в т. 10. Центр дуги — (38,25; −63,75), радиус — 25,5 мм |
| `G1 Y15` | Перемещение на рабочей подаче в т. 11 |
| `G0 Z76 M9` | Перемещение на ускоренной подаче в т. 12. Отключение подачи охлаждения |
| `G40` | Отключение коррекции на радиус |
| `X-100 Y-10 Z250` | Перемещение на ускоренной подаче в т. 0; действует G0 |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |

I и J задают смещение центра дуги относительно её начальной точки.
