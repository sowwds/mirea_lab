### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 05` | `%` — символ главного кадра и начала УП. 05 — номер УП |
| `T2 M6` | Вызов инструмента, расположенного во 2-м гнезде инструментального магазина. M6 — автоматическая смена инструмента |
| `G90` | Все координаты будут заданы в абсолютной системе координат |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G41 D1` | Включение коррекции на радиус; инструмент слева от детали. В корректоре D1 задан радиус фрезы 4 мм |
| `G0 X16,4 Y104 Z5` | Перемещение на ускоренной подаче в т. 1 |
| `S7962` | Установка рабочей частоты вращения шпинделя n = 7962 об/мин |
| `Z-10` | Перемещение на ускоренной подаче в т. 2; действует G0 |
| `G1 G94 Y32,8 F159 M8` | Перемещение на рабочей подаче в т. 3. Включение подачи охлаждения. Минутная подача — 159 мм/мин |
| `X32,8 Y16,4` | Перемещение на рабочей подаче в т. 4 |
| `X49,2` | Перемещение на рабочей подаче в т. 5 |
| `X65,6 Y32,8` | Перемещение на рабочей подаче в т. 6 |
| `Y104` | Перемещение на рабочей подаче в т. 7 |
| `G0 Z5 M9` | Перемещение на ускоренной подаче в т. 8. Отключение подачи охлаждения |
| `G40` | Отключение коррекции на радиус |
| `X50 Y300 Z100` | Перемещение на ускоренной подаче в т. 0; действует G0 |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |
