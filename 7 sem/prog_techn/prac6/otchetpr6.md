### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 06` | `%` — символ главного кадра и начала УП. 06 — номер УП |
| `T3 M6` | Вызов фрезы Ø12 мм из 3-го гнезда инструментального магазина. M6 — автоматическая смена инструмента |
| `G90` | Все координаты будут заданы в абсолютной системе координат |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G0 X-26 Y36.5 Z10` | Перемещение на ускоренной подаче в т. 1 |
| `S6635` | Установка рабочей частоты вращения шпинделя n = 6635 об/мин |
| `G1 G94 Z-15 F398 M8` | Перемещение на рабочей подаче в т. 2. Включение подачи охлаждения. Минутная подача — 398 мм/мин |
| `X-41 Y26.5` | Перемещение на рабочей подаче в т. 3 |
| `X-67.8` | Перемещение на рабочей подаче в т. 4 |
| `Y63.7` | Перемещение на рабочей подаче в т. 5 |
| `X-14.2` | Перемещение на рабочей подаче в т. 6 |
| `Y26.5` | Перемещение на рабочей подаче в т. 7 |
| `X-41` | Перемещение на рабочей подаче в т. 3; замыкание контура |
| `X-56 Y36.5` | Перемещение на рабочей подаче в т. 8 |
| `G0 Z10 M9` | Перемещение на ускоренной подаче в т. 9. Отключение подачи охлаждения |
| `X-50 Y100 Z150` | Перемещение на ускоренной подаче в т. 0; действует G0 |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |
