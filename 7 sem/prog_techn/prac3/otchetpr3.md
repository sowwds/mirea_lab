# Практическое занятие № 3

**Вариант 9:** `200* = 290 мм`, `300* = 260 мм`. (290 - 20) / 60 = 4.5 следовательно 5 проходов 10 точек


### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 03` | `%` — символ главного кадра и начала УП. 03 — номер УП |
| `T1 M6` | Вызов инструмента, расположенного во 2-м гнезде инструментального магазина. M6 — автоматическая смена инструмента |
| `G90` | Все координаты будут заданы в абсолютной системе координат |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G0 X315 Y20 Z50` | Перемещение на ускоренной подаче в т. 1 |
| `S1393` | n = (350 · 1000) / (π · 80) ≈ 1393 об/мин |
| `G1 G94 X-45 F223 M8` | Перемещение на рабочей подаче в т. 2. Включение подачи охлаждения. Sм = 0,02 · 8 · 1393 ≈ 223 мм/мин |
| `G0 Y80 M9` | Перемещение на ускоренной подаче в т. 3. Отключение подачи охлаждения |
| `G1 X315 M8` | Перемещение на рабочей подаче в т. 4. Включение подачи охлаждения |
| `G0 Y140 M9` | Перемещение на ускоренной подаче в т. 5. Отключение подачи охлаждения |
| `G1 X-45 M8` | Перемещение на рабочей подаче в т. 6. Включение подачи охлаждения |
| `G0 Y200 M9` | Перемещение на ускоренной подаче в т. 7. Отключение подачи охлаждения |
| `G1 X315 M8` | Перемещение на рабочей подаче в т. 8. Включение подачи охлаждения |
| `G0 Y260 M9` | Перемещение на ускоренной подаче в т. 9. Отключение подачи охлаждения |
| `G1 X-45 M8` | Перемещение на рабочей подаче в т. 10. Включение подачи охлаждения |
| `G0 X410 Y110 Z250 M9` | Перемещение на ускоренной подаче в т. 0. Отключение подачи охлаждения |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |
