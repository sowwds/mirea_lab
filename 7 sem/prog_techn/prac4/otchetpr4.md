### Управляющая программа

| Кадры УП | Комментарии |
|---|---|
| `% 04` | `%` — символ главного кадра и начала УП. 04 — номер УП |
| `T2 M6` | Вызов инструмента, расположенного во 2-м гнезде инструментального магазина. M6 — автоматическая смена инструмента |
| `G90` | Все координаты будут заданы в абсолютной системе координат |
| `G97 M3 S800` | Включение вращения шпинделя с инструментом; n = 800 об/мин |
| `G42 D1` | Включение коррекции на радиус; инструмент справа от детали |
| `G0 X25 Y130.5 Z20` | Перемещение на ускоренной подаче в т. 1 |
| `S2654` | n = (250 · 1000) / (π · 30) ≈ 2654 об/мин |
| `G1 G94 X-95.86 F106 M8` | Перемещение на рабочей подаче в т. 2. Включение подачи охлаждения. Sм = 0,01 · 4 · 2654 ≈ 106 мм/мин |
| `X-117.5 Y86.36` | Перемещение на рабочей подаче в т. 3 |
| `Y14.5` | Перемещение на рабочей подаче в т. 4 |
| `X25` | Перемещение на рабочей подаче в т. 5 |
| `G40` | Отключение коррекции на радиус |
| `G0 X50 Y50 Z150 M9` | Перемещение на ускоренной подаче в т. 0. Отключение подачи охлаждения |
| `M5` | Отключение вращения шпинделя |
| `M2` | Конец УП |
