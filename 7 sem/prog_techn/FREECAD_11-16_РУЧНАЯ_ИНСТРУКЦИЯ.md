# Практические 11–16 в FreeCAD: как сделать руками

Для FreeCAD 1.1.4 с английским интерфейсом. Здесь описан **текущий упрощённый вариант**: 11–12 — только боковой контур, 13–14 — карман на одном уровне, 15–16 — сверление. Названия пунктов меню можно найти через поиск команд FreeCAD.

## 1. Общие действия

1. **File → New** — новый документ.
2. Выбери рабочую среду **Part Design** для эскизов и выдавливания или **Part** для примитивов и булевых операций.
3. **Ctrl+Shift+S** — сохрани проект в папку соответствующей практики.
4. Выделить объект и нажать **Space** — скрыть/показать. Координаты и размеры меняются снизу слева во вкладке **Data**.
5. Если работаешь с готовым проектом, **File → Open → model…FCStd**. Моделирование повторять не нужно: переходи к настройке CAM.

В практиках 11–14 ноль находится справа снизу на нижней плоскости детали. В 15–16 — слева сверху на верхней плоскости. Если построить модели в координатах ниже, дополнительно переносить ноль Job не требуется.

## 2. Практики 11–12: боковой контур

Файл: [model11-12.FCStd](prac11-12/model11-12.FCStd).

### Построить модель

1. **Part Design → Create body → Create sketch → XY plane**.
2. Инструментом **Polyline** начерти замкнутый контур основания по точкам, мм:

   `(-150; 0) → (0; 0) → (0; 100) → (-100; 100) → (-150; 50) → начало`.

3. Задай координаты вершин размерными ограничениями Sketcher: горизонтальное/вертикальное расстояние от начала координат. Закрой эскиз → **Pad**, высота **20 мм**.
4. **Create sketch → XY plane**. В свойствах эскиза задай **Attachment Offset → Position → Z = 20 мм**, затем открой эскиз двойным щелчком. Нарисуй верхнюю ступень:

   `(-140; 10) → (0; 10) → (0; 90) → (-95,86; 90) → (-140; 45,86) → начало`.

5. Закрой эскиз → **Pad**, высота **10 мм**. Общая высота детали — **30 мм**.
6. Для заготовки создай отдельный эскиз основания из п. 2. В среде **Part → Extrude** вытяни его на **30 мм**, включив создание твёрдого тела. Назови объект **Blank**. Это отдельный объект, не часть готовой детали.

В текущем варианте верх заготовки уже готов. **Facing / торцевание не добавлять.**

### Создать Job и инструмент

1. Выдели готовую деталь, а не Blank → переключись в **CAM → Job**.
2. В настройках Job открой **Stock** → вариант заготовки из существующего объекта (**Existing solid**) → выбери **Blank**.
3. В разделе **Tools** добавь концевую фрезу **Endmill Ø30**. У контроллера инструмента задай:

   | Поле | Значение |
   |---|---:|
   | Tool Number | 2 |
   | Diameter | 30 mm |
   | Horiz Feed | 800 mm/min |
   | Vert Feed | 250 mm/min |
   | Spindle Speed | 4000 rpm |

4. Подтверди Job. В дереве должен быть один рабочий инструмент T2.

### Задать простой маршрут

Для точного повторения нашего открытого обхода используется **Custom**, то есть вручную заданный фрагмент пути.

1. Выдели **Job → CAM → Custom**.
2. Выбери инструмент **T2**, охлаждение **Flood**.
3. В поле G-code вставь этот фрагмент:

   ```gcode
   G0 Z40
   G0 X25 Y105
   G0 Z35
   G1 Z20 F4.166667
   G1 X-95.86 Y105 F13.333333
   G3 X-106.466602 Y100.606602 Z20 I0 J-15 K0 F13.333333
   G1 X-150.606602 Y56.466602 F13.333333
   G3 X-155 Y45.86 Z20 I10.606602 J-10.606602 K0 F13.333333
   G1 X-155 Y10 F13.333333
   G3 X-140 Y-5 Z20 I15 J0 K0 F13.333333
   G1 X25 Y-5 F13.333333
   G0 Z40
   ```

4. Нажми **OK**, назови операцию **OpenContour**.
5. Нажми **Ctrl+S**.

**Почему F здесь дробные:** внутри CAM подачи хранятся в мм/с. `13.333333` соответствует 800 мм/мин, `4.166667` — 250 мм/мин. После постобработки в `.nc` будут обычные F800 и F250. Этот фрагмент предназначен для поля Custom, не для прямого запуска на станке.

Путь: заход справа → верхняя сторона → скос → левая сторона → нижняя сторона → выход справа. Координаты уже учитывают радиус фрезы 15 мм. Дополнительно включать G41/G42 не нужно. В дугах оставляй **Z20 и K0** — это нужно для корректной работы Legacy Simulator.

### Показать анимацию

1. Закрой панель текущей операции/симуляции кнопкой **Cancel/Close**.
2. **File → Open → [animate11-12.FCMacro](prac11-12/animate11-12.FCMacro)**.
3. **Macro → Execute Macro**, сочетание **Ctrl+F6**.
4. В панели с пометкой **BRep** нажми **▶**. Должна быть одна операция OpenContour.
5. **Pause** — пауза, **Step** — одна команда, **Stop** — сброс.

Этот подготовленный макрос нужен для анимации реальной заготовки со скосом. Обычный Legacy Simulator начинает с прямоугольного ограничивающего блока. Для запуска этого макроса проект должен быть сохранён именно как `prac11-12/model11-12.FCStd`, а Job должен иметь стандартное имя `Job`. Сначала сохрани документ; при работе с копией в другой папке измени путь `PROJECT` в начале макроса.

## 3. Практики 13–14: закрытый карман

Файл: [model13-14.FCStd](prac13-14/model13-14.FCStd).

### Построить модель

1. **Part Design → Create body → Create sketch → XY**.
2. Нарисуй прямоугольник от **(-100; 0)** до **(0; 100)** → закрой эскиз → **Pad = 30 мм**.
3. **Create sketch → XY plane**. В свойствах эскиза задай **Attachment Offset → Position → Z = 30 мм**, затем открой эскиз.
4. Начерти замкнутый контур кармана по [виду сверху](prac13-14/model_top.png) и рисунку методички:

   - границы: **X = −85…−15**, **Y = 15…85 мм**;
   - верхние скругления — **R20**, нижнее левое — **R15**;
   - вогнутый участок справа снизу — **R30**, центр **(-15; 15)**;
   - два сопряжения с ним — **R8**.

5. Для сопряжений используй дуги Sketcher и ограничения **Coincident**, **Tangent**, **Radius**. Контур должен быть замкнут без разрывов. Размеры 7,82 / 23,01 / 21,32 на исходном рисунке округлены: не задавай их одновременно с точными радиусами и касательностью.
6. Закрой эскиз → **Pocket = 10 мм**. Дно окажется на **Z20**, не на Z10.

### Настроить обработку

1. Выдели готовую деталь → **CAM → Job**.
2. В **Stock** выбери прямоугольную заготовку **100 × 100 × 30 мм** без дополнительных припусков. Минимальные координаты: **(-100; 0; 0)**.
3. Добавь **Endmill Ø10**, номер **T5**. Параметры: **Horiz Feed = 1600 mm/min**, **Vert Feed = 250 mm/min**, **Spindle Speed = 8000 rpm**.
4. Подтверди Job. Скрой заготовку, чтобы можно было выбрать дно кармана.
5. Выдели плоское дно → **CAM → Pocket Shape** → выбери **T5**.
6. Установи параметры. Если поля нет в диалоге, после OK выдели операцию и найди его во вкладке **Data**:

   | Поле | Значение |
   |---|---:|
   | Start Depth | 30 mm |
   | Final Depth | 20 mm |
   | Step Down | 10 mm |
   | Clearance Height | 40 mm |
   | Safe Height | 35 mm |
   | Pattern / Clearing Pattern | Offset |
   | Step Over | 40% |
   | Keep Tool Down | true |
   | Min Travel | true |
   | Coolant | Flood |

7. **OK → Ctrl+S**. Все рабочие обходы должны лежать на **Z20**. Внутренние проходы оставь: они выбирают середину кармана.
8. Для анимации выдели **Job → CAM → Legacy CAM Simulator → ▶**. Скорость регулируется **Speed**, точность — **Accuracy**. Для демонстрации достаточно точности около **0,2 мм**.

## 4. Практики 15–16: три отверстия

Файл: [model15-16.FCStd](prac15-16/model15-16.FCStd).

### Построить модель

Простой способ с точными коническими доньями — через примитивы Part.

1. **Part → Primitives → Cube**: **Length = 80**, **Width = 40**, **Height = 20 мм**.
2. Через **Data → Placement → Position** поставь блок в **X0, Y−40, Z−20**. Верхняя грань будет Z0.
3. Создай три цилиндра радиусом **5 мм**. Их положения и высоты:

   | Отверстие | X | Y | Z основания цилиндра | Height |
   |---|---:|---:|---:|---:|
   | 1 | 15 | −15 | −9,995697 | 9,995697 |
   | 2 | 45 | −30 | −14,995697 | 14,995697 |
   | 3, сквозное | 65 | −15 | −21 | 21 |

4. Для первых двух отверстий создай по конусу: **Radius1 = 0**, **Radius2 = 5**, **Height = 3,004303 мм**. Положения: **(15; −15; −13)** и **(45; −30; −18)**. Ось конусов направлена вверх, вдоль +Z.
5. Выдели три цилиндра и два конуса с **Ctrl** → **Part → Boolean → Union**.
6. Сначала выдели блок, затем с **Ctrl** объединённые тела отверстий → **Part → Boolean → Cut**.

### Настроить сверление

1. Выдели результат Cut → **CAM → Job**.
2. Заготовка: **80 × 40 × 20 мм**, положение **(0; −40; −20)**, без припусков.
3. Добавь **Drill Ø10**, номер **T5**, угол вершины **118°**, подача **250 mm/min**, обороты **2500 rpm**.
4. Подтверди Job. Выдели окружность первого отверстия на верхней грани → **CAM → Drilling**.
5. Выбери T5 и задай:

   | Поле | Значение |
   |---|---:|
   | Start Depth | 0 mm |
   | Final Depth, отверстие 1 | −13 mm |
   | Clearance Height | 10 mm |
   | Safe Height | 5 mm |
   | Retract Height / R | 3 mm |
   | Add Tip Length | false |
   | Peck / Dwell | выключены |
   | Return Level | G98 / начальный уровень |

6. Создай ещё две отдельные операции Drilling: для второго отверстия **Final Depth = −18**, для третьего **−23,504303 мм**. Остальные параметры те же.
7. Расположи операции в порядке **1 → 2 → 3**. Убедись, что каждая выбрана только для своего отверстия.
8. **Ctrl+S → выделить Job → CAM → Legacy CAM Simulator → ▶**.

Глубины глухих отверстий отсчитываются до вершины сверла. Для сквозного отверстия уже учтены вершина и выход 0,5 мм, поэтому повторно включать Add Tip Length не нужно.

## 5. Получить G-code

1. Сначала закрой симулятор. Выдели **Job**, не SimulationResult.
2. Двойной щелчок по Job → раздел **Output / Post Processor** → выбери **fanuc**.
3. Для учебного варианта без таблицы H в аргументах используй **`--no-tlo --no-show-editor`**. В готовых проектах эти и остальные аргументы уже сохранены — существующее поле аргументов не затирай.
4. Подтверди → **CAM → Post Process** → сохрани `.nc` в папку практики.
5. Открой файл текстовым редактором. Проверь миллиметры **G21**, абсолютные координаты **G90**, подачи и обороты.
6. Сверь рабочие движения с готовыми файлами: [11–12](prac11-12/program11-12.nc), [13–14](prac13-14/program13-14.nc), [15–16](prac15-16/program15-16.nc).

Штатный Fanuc может добавлять свою обвязку, в том числе G28. В наших файлах она дополнительно настроена при экспорте; одни и те же проходы не означают побайтово одинаковую программу. Для повторения текущей учебной обвязки используй начало и завершение соответствующего `program…nc`: G21 должен стоять до первого перемещения, команды G28 и макросы с `#` из стандартной обвязки не переносятся.

Точки начала/завершения в рабочей системе координат:

| Практики | НИ: X; Y; Z, мм |
|---|---|
| 11–12 | 50; 50; 150 |
| 13–14 | −50; 350; 250 |
| 15–16 | 40; 100; 250 |

При уходе в НИ сначала поднимай Z отдельной командой, затем перемещай X/Y. Наш формат рассчитан на учебную привязку предварительно настроенного инструмента по кончику, с G49, без G43/H.

## 6. Что сохранить для отчёта

1. `.FCStd` и `.nc` — в папке своей практики.
2. Скриншот готовой модели.
3. Скриншот видимой траектории.
4. Скриншот результата симуляции.
5. Для 15–16 — разрез, показывающий два глухих отверстия и одно сквозное. В готовом проекте выдели **SectionAA** и нажми **Space**, а исходную деталь скрой.

В 11–12 торцевание исключено по выбранному упрощению, хотя присутствует в исходном задании. В 11–14 проход на всю глубину 10 мм принят для учебной демонстрации; работа на реальном станке не проверялась.
