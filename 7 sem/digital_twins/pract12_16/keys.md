# Практическая 12–16 — управление

Сцена: `twins_proj/Assets/Practice1216ConstructionSite.unity`.

Клик по технике выбирает её, включает камеру от третьего лица и захватывает курсор; снизу появляется памятка. Управляется только выбранная машина. **Esc** возвращает общий вид площадки и свободный курсор для выбора другой машины.

## Камера

- Колесо мыши — приближение и отдаление.
- При выбранной технике: движение мыши — вращение камеры вокруг машины, без зажатия кнопок. Камера следует за машиной при движении.
- В общем виде: зажать среднюю кнопку мыши и двигать мышь — перемещение обзора.
- **Esc** — общий вид и освобождение курсора.
- **Home** — вернуть общий вид площадки.

## Все машины

- **W / S** — вперёд / назад.
- **A / D** — поворот влево / вправо.

## Экскаватор

- **Q / E** — поворот платформы.
- **R / F** — поднять / опустить стрелу.
- **T / G** — движение рукояти.
- **Y / H** — поворот ковша.
- **B**, удерживать — копать, когда ковш опущен к земле. При движении ковша в грунте земля также набирается автоматически.
- **Space** — выгрузить землю из ковша.

Для загрузки самосвала поднимите наполненный ковш, расположите его над открытой частью кузова и нажмите **Space**. Земля падает вертикально из ковша и накапливается в кузове.

Копать можно в любом месте грунтовой части площадки. Опустите ковш к поверхности и копайте: появится углубление, а в ковше — земля. Для углубления ямы опускайте ковш дальше. Поднимите стрелу, поверните платформу и нажмите **Space**: земля высыплется и образует кучу в месте падения. Процент заполнения ковша показан внизу экрана.

## Бульдозер

- **R / F** — поднять / опустить отвал.
- Камни перемещаются при толкании отвалом.
- Подведите опущенный отвал под камни, затем удерживайте **R**, чтобы поднять их. Дно и боковины удерживают камни при подъёме; для выгрузки опустите отвал клавишей **F** и сдайте назад.

## Самосвал

- **R / F** — поднять / опустить кузов.
- При подъёме кузова задний борт открывается.
- При достаточном наклоне земля высыпается из кузова и образует кучу на грунте. Объём земли в кузове показан внизу экрана.

## Автокран

- **Q / E** — поворот платформы.
- **R / F** — наклон стрелы.
- **T / G** — поднять / опустить крюк.
- **Space** — зацепить ближайший груз за петлю или отпустить его.

Изменения грунта и положения техники действуют в текущем запуске. После остановки Play Mode площадка возвращается в исходное состояние.
