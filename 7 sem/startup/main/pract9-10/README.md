# Практические занятия 9–10

## Тема

Развитие навыков принятия решений, управления рисками, коммуникации с командой и клиентами.

## Что требуется как результат

1. Презентация с разбором кейса стартапа: SWOT-анализ, альтернативные решения, оценка рисков по матрице и выбор оптимального решения с обоснованием.
2. План действий по срочному сценарию: организация коммуникации, распределение ролей и задач, обоснование выбранных шагов.
3. Сценарий диалога с потенциальным клиентом, имеющим возражения. Провести ролевую игру, получить обратную связь наблюдателей и рекомендации.

Представить и обсудить выполненные задания. Количество слайдов в методичке не задано.

Методички совпадают по заданиям; в №9 указан объём 2 академических часа, в №10 — 4.
