# Практические занятия 7–8

## Тема

Поиск инвесторов и привлечение инвестиций.

## Что требуется как результат

Подготовить цифровой питч-дек на 7–10 слайдов для выбранного гипотетического инвестора (бизнес-ангел, государство, грант или фонд):

- Проблема, которую решает стартап.
- Решение и отличия от конкурентов.
- Команда и стадия зрелости проекта.
- Цели финансирования.

Выступить с питчем на 1,5–2 минуты. Получить обратную связь и зафиксировать зоны роста.
