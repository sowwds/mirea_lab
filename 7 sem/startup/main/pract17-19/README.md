# Практические занятия 17–19

## Тема

Регистрация компании. Юридические аспекты.

## Что требуется как результат

Подготовить презентацию на 10–12 слайдов:

- Базовая структура будущей компании: юридический адрес, ФИО директора и размеры долей.
- Комплект шаблонов документов для регистрации ООО: устав, заявление, протокол, решение о создании.
- Выбранный налоговый режим с обоснованием и примерным расчётом налоговых обязательств за квартал.
- Финансово-административный план первого месяца после регистрации: действия, сроки, ответственные и внешние сервисы (банк, бухгалтерия, ЭДО).

Представить проект и обсудить административные и юридические риски.
