# Практические занятия 29–30

## Тема

Изучение новейших технологий и трендов в индустрии, применение инноваций для развития стартапа.

## Что требуется как результат

Подготовить презентацию на 8–10 слайдов:

- Обзор 3 актуальных для стартапа технологических трендов: суть, применение и уровень зрелости.
- Гипотеза применения одной из технологий в продукте: ожидаемая ценность, риски и шаги пилотной реализации.
- Подборка русскоязычных и международных источников для регулярного мониторинга технологий с обоснованием выбора каждого ресурса.

Представить результаты и обсудить релевантность и реалистичность внедрения.

Файлы с суффиксом `(1)` — побайтные копии соответствующих методичек без суффикса.
