# Практические занятия 27–28

## Тема

Поиск потенциальных партнёров, установление стратегических партнёрств для роста стартапа.

## Что требуется как результат

Подготовить презентацию на 8–10 слайдов:

- Краткое описание стартапа и текущей стадии развития.
- Приоритетные типы партнёрств с обоснованием выбора.
- Перечень 3–5 потенциальных компаний или организаций-партнёров с причинами выбора.
- Макет партнёрского предложения: структура письма или презентации для первого контакта, цели, формат и ценность сотрудничества.
- Короткий питч о стартапе.

Представить предложение и обсудить реалистичность взаимодействия.
