# Serenity Landing Page — Design Spec

**Date:** 2026-05-14  
**Status:** Approved

## Overview

Публичная приветственная страница сервиса Serenity. Отображается для всех неавторизованных пользователей вместо прямого редиректа на `/auth`. Стиль — тёмная космическая тематика, в точности соответствующая текущему дизайну приложения. Референс по структуре: openai.com/codex (sticky nav, text-demo чередование, scroll-анимации).

---

## Роутинг (изменения в App.jsx)

| Путь | Компонент | Доступность |
|------|-----------|-------------|
| `/` | `LandingPage` | Публичный |
| `/auth` | `AuthPage` | Публичный (редирект → `/app` если авторизован) |
| `/app` | `Universe` | Приватный (редирект → `/auth` если нет токена) |

**Изменения:**
- `App.jsx`: добавить маршрут `/` → `LandingPage`, переименовать `/` → `/app` для Universe
- `Universe.jsx`: путь редиректа остаётся `/auth` (уже верно)
- `AuthPage.jsx`: редирект при наличии токена изменить с `/` на `/app`

## Секция 3 — Демо чата

**Лейаут:** flex/grid, текст слева + Chat UI справа (на мобиле — столбец)  
**Фон секции:** `#050716`  
**Атмосферный фон:** `example9-16.png` (вертикальная планета) — `position: absolute; right: 0; opacity: 0.2; mask-image: gradient`

**Текст слева:**
- Лейбл: `ВОЗМОЖНОСТЬ 1`
- Заголовок: "Ваш личный собеседник"
- Описание: "Обсуждайте то, что вас волнует, без осуждения и страха. Наш ИИ поможет найти корень проблемы."
- Кнопка: "Начать диалог →" → `/auth`

**LandingChat.jsx:**
- Контейнер: `rounded-2xl bg-white/4 border border-white/10 backdrop-blur-xl h-[400px]`
- **Автоплей сценарий** (useEffect, задержки через setTimeout):
  1. +800ms: "Привет! Я Serenity. Расскажи, что тебя беспокоит — я здесь, чтобы выслушать." (бот)
  2. +2200ms: "Последнее время чувствую себя подавленным..." (пользователь, печатается посимвольно)
  3. +3800ms: typing dots
  4. +5000ms: "Понимаю, это непросто. Ты не одинок в этом. Можешь рассказать побольше — когда это началось?" (бот)
  5. +6800ms: "Наверное, после смены работы" (пользователь)
  6. +7500ms: typing dots — остаётся висеть (имитация «живой» беседы)
- После завершения автоплея — инпут активируется
- Отправка сообщения → через 1200ms бот отвечает: *"Это демо-версия Serenity. Зарегистрируйтесь, чтобы начать настоящий диалог!"*
- Компоненты `SentMessage.jsx` и `ReceivedMessage.jsx` переиспользуются напрямую
- Typing dots — CSS анимация (уже есть паттерн в проекте)

**Анимация секции:** при входе в viewport — текст слетает слева, UI справа.

**Текст справа:**
- Лейбл: `ВОЗМОЖНОСТЬ 2`

- Кнопка: "Начать отслеживать →" → `/auth`

**LandingStats.jsx:**
- Стиль панели: `rounded-2xl bg-white/4 border border-white/10 backdrop-blur-xl p-5`
- Вкладки Day/Week/Month/All time — **работают** (переключают hardcoded данные)
- Иконки эмоций: цветные круги с CSS-градиентами вместо Three.js GLB (без тяжёлого рендера)
- Прогресс-бары анимированы через CSS transition при переключении периода — компонент `AnimatedProgressBar` реализован inline в `LandingStats.jsx` (он из EmotionalStats.jsx не экспортируется, логика простая: `useEffect` сбрасывает в 0 и через 50ms ставит целевое значение, CSS `transition-width` делает анимацию)
- Hardcoded данные для 5 эмоций × 4 периода

**Hardcoded данные (пример):**

## Анимации (общие принципы)

| Паттерн | Реализация |
|---------|-----------|
| Hero reveal | GSAP stagger при монтировании |
| Секции при скролле | Intersection Observer (native) + CSS класс `animate-in` |
| Карточки | `translateY(24px) → 0` + `opacity: 0 → 1`, transition 0.5s |
| Прогресс-бары | CSS transition width (уже есть в AnimatedProgressBar) |
| FAQ accordion | CSS transition height/max-height |
| Hover кнопок | Уже есть через `.btn-universal` |
| Typing dots в чате | CSS animation (уже есть в проекте) |

**Принцип:** никакого heavy Three.js. Весь эффект "живости" через CSS transitions, GSAP (уже в зависимостях), и Intersection Observer.
