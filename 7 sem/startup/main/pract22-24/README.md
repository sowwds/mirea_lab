# Практические занятия 22–24

## Тема

Подготовка к ИТ-аккредитации.

## Что требуется как результат

Подготовить презентацию на 10–12 слайдов:

- Краткое описание компании и проверка соответствия требованиям ИТ-аккредитации с обоснованием каждого критерия.
- Выявленные проблемы и меры по их устранению.
- Пакет документов для заявки: макеты сканов, справок и заявлений; список подготовленных документов и проверка корректности сведений о компании.
- Пошаговый план подачи заявки: действия, сроки и ответственные.
- Риски прохождения процедуры и способы их минимизации.

Представить ситуацию компании, документы и стратегию подачи заявки.
