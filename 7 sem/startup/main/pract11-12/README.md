# Практические занятия 11–12

## Тема

Разработка стратегий для управления кризисными ситуациями, адаптация к изменениям на рынке.

## Что требуется как результат

1. Анализ предложенного кризисного кейса: причины кризиса, прогноз последствий и меры стабилизации.
2. Антикризисная стратегия на основе анализа: конкретный план действий, распределение ролей и коммуникационная стратегия.
3. План адаптации стартапа к предложенному изменению рынка: конкретные шаги и изменения стратегии.

Представить стратегии, обсудить сильные и слабые стороны решений и получить обратную связь. Формат отчёта и количество слайдов в методичке не заданы.
