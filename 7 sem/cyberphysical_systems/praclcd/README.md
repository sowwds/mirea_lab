# Практическая работа 2 — TFT ILI9341

Интерактивная надпись `RTU MIREA` управляется двумя потенциометрами: A3 изменяет X, A2 — Y. Кнопка на D4 переключает цвет и размер шрифта. Надпись обновляется не чаще 20 раз в секунду, а старое положение стирается локально — без очистки всего экрана.

## Сборка

В терминале VS Code, открытом в папке `prac2`, выполните:

```bash
arduino-cli compile --fqbn STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_C031C6,opt=oslto --libraries libraries --output-dir .build .
```

После каждого изменения `prac2.ino` повторите сборку. Затем откройте `diagram.json` и нажмите зелёный Play в Wokwi. Прошивка занимает около 94% Flash, поэтому не убирайте `opt=oslto` из команды.

> В `libraries/Adafruit_ILI9341` находится изолированная копия библиотеки с одной правкой для совместимости с STM32Duino 3. Это не влияет на библиотеки других проектов.
