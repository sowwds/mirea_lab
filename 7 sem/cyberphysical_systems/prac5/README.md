# Практическая работа №5 — сервопривод и шаговый двигатель

**Тема:** «Принцип работы функциональных устройств. Управление сервоприводом и шаговым двигателем».

STM32 Nucleo-C031C6, C и STM32 HAL, как в prac2–4. Схема предназначена для Wokwi.

## Управление

- Вращение потенциометра задаёт положение серво от 0° до 180°. Среднее положение — около 90°.
- Держать зелёную кнопку **CW** или клавишу **D** — шаговик вращается по часовой стрелке.
- Держать синюю кнопку **CCW** или клавишу **A** — против часовой стрелки.
- Отпустить кнопки — остановка. При двух одновременно нажатых кнопках двигатель также стоит.

Клавиши работают, когда запущен симулятор и фокус находится на схеме. В атрибутах кнопок отключён моделируемый дребезг (`bounce: "0"`).

## Подключение

| Контакт STM32 | Элемент |
| --- | --- |
| D11 / PA7 / TIM3_CH2, AF1 | Servo PWM |
| 5V, GND | Servo V+, GND |
| A0 / PA0 / ADC1_IN0 | Потенциометр SIG |
| 3V3, GND | Потенциометр VCC, GND |
| D2 / PA10 | CW: контакт 1; контакт 2 — GND |
| D3 / PB3 | CCW: контакт 1; контакт 2 — GND |
| D6 / PB5 | A4988 STEP |
| D5 / PB4 | A4988 DIR |
| 3V3 | A4988 VDD, RESET, SLEEP |
| GND | A4988 оба GND, ENABLE, MS1, MS2, MS3 |

| A4988 | Шаговый двигатель |
| --- | --- |
| 2B | A− |
| 2A | A+ |
| 1A | B+ |
| 1B | B− |

VMOT оставлен свободным: Wokwi не моделирует силовое питание A4988. На реальном устройстве требуется отдельное питание двигателя по спецификации драйвера; питание серво также выбирают по его току. Эта схема не является схемой силового питания реального стенда.

## Как устроен код

`main.c` содержит всю программу, дополнительных библиотек двигателей нет.

**Серво:** TIM3 работает от 48 МГц. Предделитель `PSC = 47` даёт отсчёт 1 мкс, `ARR = 19999` — период 20 мс (50 Гц). PA7 выдаёт аппаратный ШИМ, который продолжает работать независимо от основного цикла. Каждые 20 мс ADC1 измеряет потенциометр; значение `0..4095` преобразуется в длительность импульса `500..2500` мкс:

```c
pulse = 500U + 2000U * value / 4095U;
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_2, pulse);
```

Это диапазон для модели Wokwi; для реального сервопривода границы уточняют по его документации.

**Шаговик:** `Stepper_Update()` читает кнопки с внутренними подтяжками вверх: нажатие даёт ноль. DIR определяет направление, STEP переключается примерно каждые 2 мс. На каждый положительный фронт приходится один шаг: около 250 шагов/с, или 75 об/мин при 200 шагах на оборот. При MS1–MS3 = 0 выбран полный шаг 1,8°. Это номинальная скорость: опрос и измерение АЦП могут немного увеличить интервалы.

Смена направления выполняется при низком STEP с ожиданием перед следующим фронтом. При остановке импульсы прекращаются, но драйвер остаётся включённым. Серво и шаговик управляются одновременно; задержек на целый оборот в программе нет.

## Сборка и запуск

```bash
cd prac5
./build-local.sh
code .
```

В VS Code открыть `diagram.json`, затем **F1 → Wokwi: Start Simulator**. После изменения `main.c` повторить сборку и перезапустить симуляцию.

Сборка использует установленное ядро `STMicroelectronics:stm32` и Arduino CLI только как инструмент сборки. Временный пустой `.ino` создаётся в `/tmp`; исходник программы — `main.c`. Прошивка и ELF сохраняются в `.build/` и подключаются через `wokwi.toml`.

Для проверки: повернуть потенциометр в оба крайних положения и в середину; удержать по очереди CW и CCW; отпустить кнопки; проверить остановку при двух нажатых кнопках. Потенциометр должен менять угол серво и во время вращения шаговика.
