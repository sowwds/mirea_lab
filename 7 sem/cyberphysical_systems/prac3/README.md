# Практическая работа №3 — аппаратный таймер TIM14

**Тема:** «Принцип работы таймера микроконтроллера. Расчёт времени таймера».

Это развитие практической работы №2. Схема светофора и его алгоритм сохранены, но системные задержки `HAL_Delay` заменены собственной функцией `TimerDelay`, которая использует счётчик аппаратного таймера `TIM14`.

## Состав папки

- `main.c` — C-код с GPIO-логикой светофора, `MX_TIM14_Init` и `TimerDelay`;
- `diagram.json` — та же схема Wokwi, что и в `prac2`;
- `build-local.sh` — локальная сборка в ELF/BIN;
- `wokwi.toml` — путь Wokwi к прошивке;
- `.build/` — создаваемый результат сборки;
- `report/` — исходник отчёта, его вложения и сформированные файлы.

## Что изменилось по сравнению с `prac2`

После настройки GPIO вызываются `MX_TIM14_Init()` и `HAL_TIM_Base_Start(&htim14)`. Таймер получает частоту 48 МГц и предделитель `48000 - 1`, поэтому счётчик увеличивается один раз в миллисекунду. Его период равен `0xFFFF`.

`TimerDelay(ms)` запоминает значение счётчика и ждёт, пока разность текущего и начального значений не достигнет `ms`. Вычитание выполняется в `uint16_t`, поэтому корректно переживает переполнение счётчика для задержек меньше 65,536 с. Наибольшая задержка проекта — 10 с.

В проекте **нет кастомной библиотеки**: используются HAL из STM32Duino и исходный `main.c`. Изолированная изменённая библиотека `Adafruit_ILI9341` относится к отдельному проекту `praclcd`, а не к этой практике.

## Требования

Требования совпадают с `prac2`:

```bash
paru -S arduino-cli
arduino-cli core update-index
arduino-cli core install STMicroelectronics:stm32
code --install-extension wokwi.wokwi-vscode
```

Для запуска локального Wokwi требуется лицензия расширения; запросить её можно через `F1` → `Wokwi: Request a new License`.

## Локальная сборка и запуск

```bash
cd prac3
./build-local.sh
code .
```

Скрипт временно создаёт в `/tmp` служебный `.ino`, потому что этого требует Arduino CLI, компилирует `main.c` и сохраняет `.build/prac1_3.ino.bin` и `.build/prac1_3.ino.elf`. Затем откройте `diagram.json` и запустите симулятор кнопкой в окне схемы либо через `F1` → `Wokwi: Start Simulator`.

После изменения `main.c` повторите `./build-local.sh`.

## Проверка

1. В начальном состоянии горят автомобильный зелёный и пешеходный красный.
2. Нажмите кнопку и проверьте тот же сценарий фаз, что в `prac2`.
3. Убедитесь, что работа схемы не изменилась, хотя в `main.c` нет вызовов `HAL_Delay`.

Инструкции по отчёту находятся в [REPORT_WORKFLOW.md](../cmd/REPORT_WORKFLOW.md).
