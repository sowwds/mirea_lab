# Практическая работа 1 — контроллер светофора

Проект повторяет схему и сценарий из методички: Nucleo-C031C6, пять светодиодов, кнопка запроса, потенциометр длительности перехода и зуммер.

## Файлы

- `prac1.ino` — исходный код Arduino/STM32Duino;
- `diagram.json` — схема Wokwi;
- `wokwi.toml` — конфигурация для локального запуска в VS Code;
- `Практическая работа №1. Контроллер светофора(1).docx` — исходная методичка.

## Запуск в VS Code

1. Установите расширение **Wokwi Simulator** и получите в нём лицензию через команду `Wokwi: Request a new License`.
2. Установите Arduino CLI и ядро STM32Duino для платы Nucleo-C031C6, затем соберите скетч. В результате должны появиться `.bin` и `.elf`.
3. В `wokwi.toml` раскомментируйте `firmware` и `elf`, указав фактические пути к файлам сборки.
4. Откройте `diagram.json` и нажмите зелёный Play либо выполните `Wokwi: Start Simulator` из палитры команд.

## Сборка

Откройте терминал VS Code именно в папке `prac1` и выполните:

```bash
arduino-cli compile --fqbn STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_C031C6 --output-dir .build .
```

Команду нужно повторять после каждого изменения `prac1.ino`, до запуска симуляции.

## Проверка

Без нажатия кнопки машины проходят фазы: зелёный → жёлтый → красный → жёлтый. Нажмите кнопку во время зелёного: пешеходная фаза начнётся только после жёлтого и красного для машин. Потенциометр задаёт длительность перехода от 3 до 10 секунд; в последние две секунды зелёный пешеходный LED мигает.
