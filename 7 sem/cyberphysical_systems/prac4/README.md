# Практическая работа №4 — ШИМ и регулирование яркости

**Тема:** «Принцип работы таймера в режиме ШИМ. Регулирование яркости светодиода».

Работа продолжает проект светофора из `prac2` и `prac3`. Схема не менялась: автомобильный зелёный светодиод подключён к D11/PA7. В этой версии PA7 работает не как обычный GPIO, а как выход `TIM3_CH2` в режиме PWM.

## Реализация

Таймер TIM3 получает частоту 48 МГц. Предделитель `48 - 1` задаёт частоту счётчика 1 МГц, а период `1000 - 1` формирует ШИМ 1 кГц. Функция `SetGreenBrightness` меняет регистр сравнения канала 2; значение от 0 до 100 задаёт коэффициент заполнения от 0% до 100%.

Пока автомобилям разрешено движение, яркость зелёного светодиода плавно изменяется от 10% до 100% и обратно с шагом 10% каждые 100 мс. Кнопка и пешеходный сценарий сохранены. Во время мигания перед переключением фазы ШИМ устанавливается поочерёдно в 0% и 100%.

## Файлы

- `main.c` — код GPIO и конфигурация TIM3 в режиме PWM;
- `diagram.json` — исходная схема светофора без новых компонентов;
- `build-local.sh` — сборка C-кода в `.build/prac4.ino.bin` и `.elf`;
- `wokwi.toml` — конфигурация локального Wokwi;
- `report/` — место для исходника отчёта и его вложений.

## Сборка и запуск

Установите Arduino CLI, ядро `STMicroelectronics:stm32` и расширение Wokwi для VS Code так же, как для [prac2](../prac2/README.md).

```bash
cd prac4
./build-local.sh
code .
```

Затем откройте `diagram.json` и запустите Wokwi. После изменения `main.c` снова выполните `./build-local.sh`.
