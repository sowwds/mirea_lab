# Лабораторная 4 — задание 1



## Таблица кадров

| Кадры УП | Комментарий |
|---|---|
| `%05` | Главный кадр, номер УП 05 |
| `T3` | Вызов инструмента в 3м гнезде|
| `G90` | Выбор системы координат - абсолютные координаты |
| `G97 M4 S400` | Включаем вращение шпинделя |
| `G0 X40 Z0` | Подвод в точку 1 перед торцом |
| `G96 S180` | Постоянная скорость резания 180|
| `G1 G95 X-4 F0.15 M8` | Переход в точку 2 |
| `G0 Z5 M9` | Переход в точку 3, отключение охлаждения |
| `G97 S400` | Холостое вращение шпинделя |
| `G0 X100 Z50` | Уход в безопасную точку |
| `M5` | Остановка шпинделя |
| `M2` | Конец программы |
