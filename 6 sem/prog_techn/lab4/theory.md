# Теория по lab4: коды, расшифровка и порядок ручной разработки УП

## 1. Что нужно принять перед составлением УП

Для этой лабораторной по методичке сначала фиксируют:

- систему координат детали;
- плоскость обработки;
- способ задания подачи;
- способ задания главного движения;
- инструмент;
- опорные точки;
- последовательность технологических переходов.

Для токарной обработки в этой работе обычно принимают:

- `Z0` на правом торце детали;
- отрицательное направление `Z` влево, в глубину детали;
- `X` задается в диаметрах;
- рабочая плоскость `XZ`, то есть `G18`;
- абсолютное программирование `G90`;
- рабочая система координат детали `G54`.

## 2. Основные G-коды, которые нужны в этой работе

### `G90`

Абсолютное программирование. Все координаты задаются относительно нуля детали.

Пример:

```nc
G90
G0 X52 Z2
```

### `G18`

Выбор плоскости `XZ`. Для токарной обработки это базовый вариант.

### `G54`

Выбор рабочей системы координат детали.

Если в методичке не сказано иное, для одной детали обычно используют именно `G54`.

### `G0`

Ускоренное перемещение. Используется только на холостых ходах:

- подвод;
- отвод;
- уход в безопасную точку;
- перемещение между переходами без резания.

Пример:

```nc
G0 X65 Z2
```

### `G1`

Линейная интерполяция с рабочей подачей. Используется на рабочих ходах, когда инструмент режет материал.

Пример:

```nc
G1 Z0 F0.2
G1 X0
```

### `G94`

Подача в мм/мин.

Для этой лабораторной обычно не применяется, потому что в таблицах режимов дана подача `So`, то есть мм/об.

### `G95`

Подача в мм/об.

Если в таблице указано `So`, нужно использовать именно `G95`.

Пример:

```nc
G95
G1 Z0 F0.15
```

### `G96`

Постоянная скорость резания.

Под адресом `S` задается именно скорость резания `v` в м/мин. Это удобно, когда в таблице переходов уже дана скорость резания.

Пример:

```nc
G96 S180 M3
```

Расшифровка:

- `G96` - режим постоянной скорости резания;
- `S180` - скорость резания `180 м/мин`;
- `M3` - вращение шпинделя по часовой стрелке.

### `G97`

Постоянная частота вращения шпинделя.

Под адресом `S` тогда задают уже не `v`, а `n` в об/мин.

Пример:

```nc
G97 S1500 M3
```

Использовать `G97` можно, если заранее посчитаны обороты шпинделя. Но если в задании дана скорость резания `v`, для ручной разработки по методичке удобнее `G96`.

### `G41`, `G42`, `G40`

Коррекция на радиус вершины резца:

- `G41` - инструмент слева от контура;
- `G42` - инструмент справа от контура;
- `G40` - отмена коррекции.

В простых ответах для этой лабораторной их обычно не включают, если преподаватель требует только базовую ручную разработку без детальной коррекции резца.

## 3. Основные M-коды

### `M3`

Вращение шпинделя по часовой стрелке.

### `M4`

Вращение шпинделя против часовой стрелки.

### `M5`

Остановка шпинделя.

### `M6`

Смена инструмента.

В методичке смена инструмента дается как `T... M6`.

Пример:

```nc
T0101 M6
```

### `M0`

Программируемый останов.

### `M1`

Останов по подтверждению (`Optional Stop`).

### `M2`

Конец программы.

По методичке это корректный код завершения главной программы.

## 4. Адреса, которые надо понимать

### `X`

Координата по оси `X`.

На токарном станке чаще всего задается в диаметрах.

### `Z`

Координата по оси `Z`.

Для этой лабораторной:

- `Z0` - правый торец;
- влево - отрицательные значения.

### `F`

Подача.

При `G95`:

- `F0.2` означает `0.2 мм/об`;
- `F0.15` означает `0.15 мм/об`.

### `S`

Скорость:

- при `G96` это скорость резания `v`;
- при `G97` это обороты шпинделя `n`.

### `T`

Номер инструмента.

## 5. Как правильно составлять УП вручную

Удобный порядок:

1. Записать начало программы: `%`, номер `O....`.
2. Задать базовые режимы: `G90`, `G18`, `G54`.
3. Вызвать инструмент: `T... M6`.
4. Задать способ подачи: `G95`.
5. Задать режим главного движения: `G96 S... M3` или `G97 S... M3`.
6. Выполнить холостой подвод `G0` к первой опорной точке.
7. Выполнить рабочие ходы `G1` по опорным точкам.
8. После перехода сделать отвод `G0`.
9. Если начинается новый переход с другими режимами, сменить `S` и `F`.
10. После окончания обработки уйти в безопасную точку, остановить шпиндель, завершить программу `M2`.

## 6. Как оформлять подрезку торца

Подрезка торца не должна записываться одной диагональю, если по смыслу нужно показать опорные точки и технологическую логику.

Правильнее так:

```nc
G0 X52 Z2
G1 Z0 F0.15
G1 X0
G0 X52 Z2
```

Логика:

- подошли к торцу;
- вышли на плоскость торца;
- подрезали до центра;
- отвели инструмент.

## 7. Как оформлять наружное точение цилиндрической поверхности

Пример для участка диаметром `35` и длиной `39`:

```nc
G0 X37 Z1
G1 X35 Z0 F0.15
G1 Z-39
G0 X65 Z5
```

Логика:

- `G0` - подвод над поверхностью;
- `G1 X35 Z0` - выход на размер и на торец;
- `G1 Z-39` - рабочий проход вдоль оси;
- `G0` - отвод.

## 8. Типовые ошибки в этой лабораторной

### Ошибка 1. Неправильный знак по `Z`

Если ноль стоит на правом торце, то все размеры влево должны идти в минус.

Правильно:

```nc
G1 Z-39
```

Неправильно:

```nc
G1 Z39
```

### Ошибка 2. Смешение холостых и рабочих ходов

`G0` используют без резания, `G1` - только при рабочей подаче.

### Ошибка 3. Использование одной диагонали вместо технологически понятных ходов

Для подрезки торца лучше отдельно показывать:

- подход к торцу;
- движение по торцу.

### Ошибка 4. Неправильная трактовка `S`

Нужно всегда смотреть, какой активен режим:

- `G96` -> `S` это `м/мин`;
- `G97` -> `S` это `об/мин`.

### Ошибка 5. Неправильная трактовка `F`

Нужно смотреть:

- `G95` -> `F` в `мм/об`;
- `G94` -> `F` в `мм/мин`.

### Ошибка 6. Использование координаты `X-...` при подрезке торца

Для простых учебных программ обычно достаточно доводить инструмент до `X0`.

## 9. Минимальный шаблон УП для этой дисциплины

```nc
%
O0100
G90 G18 G54
T0101 M6
G95
G96 S160 M3
G0 X... Z...
G1 ... F...
G1 ...
G0 X... Z...
M5
M2
```

## 10. Что особенно проверяет преподаватель

Обычно смотрят:

- правильно ли выбрана система координат;
- верно ли расставлены знаки координат;
- соответствует ли `F` табличной подаче;
- соответствует ли `S` табличной скорости резания;
- разделены ли холостые и рабочие перемещения;
- логично ли проставлены опорные точки;
- корректно ли оформлено начало и конец программы.
