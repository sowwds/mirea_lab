# Ответы на вопросы (Практическое занятие 02) Ефремов ЭФБО-10-23

**1. Какое станочное приспособление чаще всего используется для установки заготовок на токарных станках с ЧПУ? Опишите последовательность его зажима и разжима.**
Чаще всего используют трехкулачковый самоцентрирующий патрон с ручным приводом. Сначала кулачки раскрывают поворотом ключа против часовой стрелки, затем вставляют заготовку и зажимают поворотом ключа по часовой стрелке.

**2. Какие два основных типа токарных резцов выделяют по виду обрабатываемой поверхности (обработка каких поверхностей)?**
Резцы для наружной обработки и резцы для внутренней обработки.

**3. Перечислите не менее трех видов токарных резцов, классифицируемых по технологическому назначению (по типу выполняемой операции).**
Проходные, канавочные (или отрезные), резьбонарезные.

**4. Чем отличается конструкция державки (хвостовика) у резцов для наружной и внутренней обработки?**
Для наружной обработки обычно используют державку прямоугольного сечения (размеры HxB). Для внутренней обработки державка круглая, задается диаметром D.

**5. Для чего при установке инструмента на токарном станке используются вспомогательный инструмент (адаптеры) и промежуточные втулки?**
Адаптеры нужны, когда инструмент нельзя поставить прямо в гнездо револьверной головки из-за конструкции или размеров хвостовика. Промежуточные втулки используют, когда диаметр державки меньше отверстия во вспомогательном инструменте.

**6. Опишите последовательность установки токарного резца для наружной обработки непосредственно в гнездо револьверной головки.**
Ослабляют винты прижима, устанавливают резец до упора, затем винты затягивают.

**7. С какой целью при установке резца могут использоваться промежуточные пластины?**
Чтобы вывести вершину резца на линию центров станка, если высота державки меньше высоты гнезда револьверной головки.

**8. Что такое инструментальный блок (ИБ) применительно к токарной обработке? Опишите полную последовательность установки инструментального блока, состоящего из вспомогательного инструмента и расточного резца, в гнездо револьверной головки.**
Инструментальный блок — это сборка из вспомогательного и режущего инструмента. Последовательность: поставить вспомогательный инструмент по шпонке в гнездо револьверной головки, при необходимости установить промежуточную втулку, затем установить режущий инструмент (расточной резец) во вспомогательный инструмент.

**9. Какая проблема решается с помощью применения вспомогательного инструмента, учитывая, что гнезда револьверной головки имеют стандартизированные размеры, а хвостовики инструментов могут быть разными?**
Решается проблема несоответствия размеров и типа хвостовика инструмента стандартному гнезду револьверной головки; обеспечивается корректная и надежная установка.
