## 1. Представление текста в виде последовательностей

### 1.1 Последовательность индексов
Для первого предложения строки `text`:
- текст проходит через `preprocess_text`;
- строится словарь уникальных слов;
- каждому слову ставится в соответствие индекс;
- первое предложение представляется как последовательность индексов.

### 1.2 Унитарное кодирование
Унитарное кодирование (`one-hot encoding`) — это представление токена в виде вектора, где:
- одна позиция равна `1`;
- все остальные равны `0`.

Поэтому первое предложение представляется как матрица размера:
- `число слов в предложении x число уникальных слов`.

### 1.3 `nn.Embedding`
`nn.Embedding` — это слой, который преобразует индекс токена в плотный вектор (`embedding`, эмбеддинг).

В отличие от `one-hot`, эмбеддинг:
- короче по размерности;
- может обучаться;
- обычно лучше подходит для моделей по тексту.

## 2. Классификация фамилий по национальности (`ConvNet`)

### Словарь и датасет
Реализован `Vocab`, где токен — символ.

Особенности:
- добавлен специальный токен `<PAD>` с индексом `0`;
- добавлен `<UNK>` для неизвестных символов;
- в `max_seq_len` сохраняется длина самой длинной последовательности из train-части.

`SurnamesDataset`:
- превращает фамилию в последовательность индексов символов;
- дополняет ее справа индексом `<PAD>` до `vocab.max_seq_len`.

### Модель
Используется `SurnameConvClassifier`:
- `Embedding`;
- `Conv1d`;
- еще один `Conv1d`;
- `AdaptiveMaxPool1d(1)`;
- `Dropout`;
- `Linear`.

Почему так:
- `Conv1d` умеет искать локальные шаблоны в последовательности символов;
- для фамилий это полезно, потому что важны сочетания букв и их порядок.

### Два варианта по заданию
В ноутбуке реализованы оба варианта:
1. фиксированный `one-hot` через `nn.Embedding.from_pretrained(torch.eye(...), freeze=True)`;
2. обучаемый `nn.Embedding` малой размерности.

Обычно второй вариант лучше, потому что обучаемые эмбеддинги гибче и компактнее.

## 3. Классификация обзоров на фильмы (`ConvNet`)

### Подготовка данных
Используются файлы из `data/`:
- `positive_reviews.txt` или `positive_reviews.csv`;
- `negative_reviews.txt` или `negative_reviews.csv`.

Далее:
- отзывы считываются из текстовых файлов и объединяются в один датафрейм;
- положительным дается метка `1`, отрицательным — `0`;
- выполняется предобработка текста;
- train/test делятся через `train_test_split`.

### Словарь и датасет
Токен — слово.

В словаре:
- `<PAD>` — для дополнения коротких последовательностей;
- `<UNK>` — для слов, которых не было в обучающей выборке;
- используется `min_freq=5`, чтобы отсечь редкий шум.

`ReviewDataset` возвращает:
- последовательность индексов слов фиксированной длины;
- метку класса.

### Модель
Используется `ReviewConvClassifier`:
- обучаемый `Embedding`;
- три параллельных `Conv1d` с ядрами `3`, `5`, `7`;
- глобальный max-pooling;
- объединение признаков из трех сверток;
- `Dropout`;
- `Linear`.

Зачем несколько размеров ядра:
- `3` ловит короткие шаблоны;
- `5` — средние;
- `7` — более длинные фразы.

Это классическая идея текстового `CNN`.

## Обучение, метрики и память

### `device`
По условию выставлено:
```python
device = torch.device("cuda:0")
```

### `early stopping`
Используется ранняя остановка (`early stopping`):
- если `test_loss` перестает улучшаться,
- обучение завершается раньше, чтобы не тратить время и не усиливать переобучение.

### Очистка памяти
После обучения тяжелых моделей вызывается:
- `gc.collect()`;
- `torch.cuda.empty_cache()`.

Это уменьшает риск переполнения памяти видеокарты между разными блоками ноутбука.

## Термины

- `sequence` (последовательность) — упорядоченный список токенов.
- `token` (токен) — минимальная единица текста: слово или символ.
- `embedding` (эмбеддинг) — плотное векторное представление токена.
- `padding` (паддинг) — добавление специальных токенов, чтобы все последовательности были одной длины.
- `Conv1d` — одномерная свертка по последовательности.
- `pooling` (пулинг) — операция сжатия признаков.
- `accuracy` — доля правильных предсказаний.
