Этот проект содержит один основной ноутбук с выполненными заданиями:
- `Текущий контроль 1-2/Задание.ipynb`

Ниже — подробное описание того, что реализовано по каждому разделу, с пояснением терминов.

## Ключевые термины

- **Нейрон** — элемент модели, который считает взвешенную сумму входов и добавляет смещение (bias).
  Формула: `y = x @ w + b`.
- **Вес (weight)** — параметр, который умножается на входной признак.
- **Смещение (bias)** — параметр, который добавляется к сумме, позволяет сдвигать выход модели.
- **Полносвязный слой (Linear / Dense)** — набор нейронов, каждый получает все входные признаки.
- **Батч (batch)** — набор примеров, обрабатываемых одновременно. Если входы имеют форму
  `(batch_size, n_features)`, то слой обрабатывает сразу несколько строк.
- **Активация** — нелинейная функция, применяемая к выходу слоя (например, ReLU, Softmax, ELU).
- **Функция потерь (loss)** — число, показывающее, насколько плохо предсказание совпадает с правильным ответом.
- **Градиент** — производная функции потерь по параметрам. Показывает, как менять параметры, чтобы уменьшить loss.
- **Backprop (обратное распространение ошибки)** — алгоритм вычисления градиентов от выхода к входу.

## 1. Создание нейронов и полносвязных слоев

### Что сделано
- Реализован класс `Neuron` с прямым проходом `inputs @ weights + bias`.
- Реализован класс `Linear` для одного входного вектора и для батча (матрицы входов).
- Добавлена версия `Linear(n_features, n_neurons)` с инициализацией весов из стандартного нормального распределения.
- Показан пример прохождения данных через два слоя, чтобы на выходе получить матрицу размера `(3, 7)`.

### Что важно понять
- Оператор `@` — матричное умножение.
- Для одного примера вход имеет форму `(n_features,)`, для батча — `(batch_size, n_features)`.
- Веса слоя имеют форму `(n_features, n_neurons)`, а смещения — `(n_neurons,)`.
- При батч‑входе смещение автоматически «добавляется» ко всем строкам (broadcasting).

## 2. Функции активации

### ReLU
- Формула: `ReLU(x) = max(0, x)`.
- Зачем: вводит нелинейность, обнуляет отрицательные значения.

### Softmax
- Преобразует вектор логитов в вероятности, сумма по классам равна 1.
- Формула: `softmax(x_i) = exp(x_i) / sum_j exp(x_j)`.
- Важно: для численной устойчивости из каждого логита вычитается максимум по строке.

### ELU
- Формула: `ELU(x) = x`, если `x > 0`, иначе `alpha * (exp(x) - 1)`.
- Зачем: мягче работает с отрицательными значениями, чем ReLU.

## 3. Функции потерь

### MSE (Mean Squared Error)
- Формула: `mean((y_pred - y_true)^2)`.
- Применяется для регрессии.

### Categorical Cross-Entropy
- Используется для классификации.
- Считается по вероятности правильного класса после Softmax.
- Чтобы избежать `log(0)`, вероятности ограничиваются через `clamp`.

### L2-регуляризация
- Добавляет штраф `lambda * sum(W^2)` к потере.
- Смысл: ограничивает рост весов, снижает риск переобучения.

## 4. Обратное распространение ошибки

### 4.1 SGD (по одному примеру)
- Реализован `SquaredLoss` и производная по выходу.
- В `Neuron` добавлены градиенты:
  - `dweights` — производная loss по весам.
  - `dbias` — производная loss по смещению.
- В цикле обучения: forward → loss → backward → шаг оптимизации.

### 4.2 Пакетный градиентный спуск
- `MSELoss.backward` модифицирован для батча (деление на размер батча).
- `Neuron.backward` считает градиенты по всему батчу.
- На каждом шаге используется вся выборка.

### 4.3 Полносвязный слой с backprop
- В `Linear` добавлен метод `backward`:
  - `dweights = X.T @ dvalues`
  - `dbiases = sum(dvalues)`
  - `dinputs = dvalues @ W.T`
- Показано обучение линейной регрессии с одним нейроном.

### 4.4 Небольшая нейросеть
- Сеть `Linear(1→10) → ReLU → Linear(10→1)` обучается аппроксимировать `y = x^2 + шум`.
- Реализован полный проход forward/backward и шаги оптимизации по обоим слоям.
- Промежуточные результаты сохраняются для визуализации кривых обучения.

#### Подробно по коду 4.4

Исходные данные:
- `X = torch.linspace(-1, 1, 100).view(-1, 1)` — 100 точек от -1 до 1, форма `(100, 1)`.
- `y = X.pow(2) + 0.2 * torch.rand(X.size())` — целевая квадратичная зависимость с шумом.

Компоненты сети:
- `fc1 = Linear(n_features=1, n_neurons=10)` — первый полносвязный слой.
  Вход: `(100, 1)` → выход: `(100, 10)`.
- `relu1 = Activation_ReLU()` — нелинейность ReLU.
- `fc2 = Linear(n_features=10, n_neurons=1)` — второй слой.
  Вход: `(100, 10)` → выход: `(100, 1)`.

Прямой проход (forward):
- `out1 = fc1.forward(X)` — линейное преобразование признаков.
- `out2 = relu1.forward(out1)` — нелинейность: обнуляет отрицательные значения.
- `out = fc2.forward(out2)` — итоговое предсказание формы `(100, 1)`.

Функция потерь:
- `data_loss = loss.forward(out, y)` — MSE между предсказанием и истинными значениями.

Сохранение промежуточных результатов:
- Каждые 200 эпох `out` копируется в `ys`.
  Это нужно, чтобы потом построить несколько графиков и увидеть, как линия
  приближается к точкам по мере обучения.

Обратный проход (backward):
- `loss.backward(out, y)` — градиент потерь по выходу сети.
- `fc2.backward(loss.dinput)` — градиенты по `W2`, `b2` и по входу `fc2`.
- `relu1.backward(fc2.dinputs)` — обнуляет градиенты там, где вход был ≤ 0.
- `fc1.backward(relu1.dinputs)` — градиенты по `W1`, `b1` и по входу `fc1`.

Шаг оптимизации:
- `fc1.weights -= lr * fc1.dweights`, `fc1.biases -= lr * fc1.dbiases`.
- `fc2.weights -= lr * fc2.dweights`, `fc2.biases -= lr * fc2.dbiases`.
  Это обычный градиентный спуск: параметры двигаются в сторону уменьшения loss.

Визуализация:
- В конце строятся графики: желтые точки — реальные данные `y`,
  зеленая линия — предсказание сети `out` на разных эпохах.
