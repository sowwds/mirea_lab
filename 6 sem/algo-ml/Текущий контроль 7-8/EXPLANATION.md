## 1. Представление и предобработка текстовых данных

### `preprocess_text(text: str)`
Функция делает базовую предобработку текста:
- приводит текст к нижнему регистру;
- заменяет все символы, кроме букв и знаков `. ! ?`, на пробелы;
- убирает лишние пробелы;
- выполняет токенизацию (`tokenization`, разбиение текста на токены);
- убирает сами знаки пунктуации из списка токенов;
- применяет стемминг (`stemming`, приведение слова к укороченной основе).

### Бинарное кодирование предложения
Для первого предложения из `text` строится тензор `sentence_t`.

Смысл такой:
- формируется словарь (`Vocab`) из всех уникальных слов;
- для каждого слова есть индекс;
- если слово есть в первом предложении, на этой позиции стоит `1`, иначе `0`.

Это называется бинарным кодированием (`binary encoding`), потому что модель видит только факт наличия слова, а не количество повторений.

## 2. Классификация фамилий по национальности

### Подготовка данных
Используется файл `data/surnames.csv`.

В ноутбуке:
- считывается CSV;
- колонка `nationality` кодируется в числа через `LabelEncoder`;
- данные делятся на обучающую и тестовую выборки через `train_test_split`.

### `Vocab` для фамилий
В этой задаче токен — это символ.

То есть словарь состоит не из слов, а из букв, которые встречаются в фамилиях обучающей выборки.

### `SurnamesDataset`
Класс датасета:
- хранит фамилии и метки классов;
- умеет превращать фамилию в бинарный вектор;
- возвращает пару `(X, y)`.

Векторизация фамилии работает так:
- берем фамилию;
- проходим по ее символам;
- если символ есть в словаре, ставим `1` в соответствующую позицию.

Это означает, что модель видит набор символов, которые присутствуют в фамилии.

### `SurnameClassifier`
Это `MLP` (`Multi-Layer Perceptron`, многослойный перцептрон).

Архитектура:
- `Linear(input_dim -> 128)`;
- `ReLU` (`Rectified Linear Unit`, функция активации, которая обнуляет отрицательные значения);
- `Dropout(0.2)`;
- `Linear(128 -> output_dim)`.

Что делает модель:
- получает бинарный вектор символов;
- пытается по набору букв предсказать национальность.

После обучения:
- считается `accuracy` (`accuracy`, доля правильных ответов);
- для нескольких фамилий выводятся 3 наиболее вероятных предсказания.

## 3. Классификация обзоров ресторанов

### Подготовка данных
Используется файл `data/raw_train.csv`.

Важный момент: файл читается как CSV без заголовка:
- `header=None`
- `names=['rating', 'text']`

Это нужно, потому что в датасете первая строка — уже данные, а не имена колонок.

Далее:
- из датасета берется только 10% строк, как требует задание;
- рейтинг кодируется числами через `LabelEncoder`;
- данные делятся на train/test.

### `Vocab` для обзоров
Здесь токен — уже слово, а не символ.

Словарь строится по всем словам из обучающей части после `preprocess_text`.

### `ReviewDataset`
Класс датасета:
- хранит тексты отзывов и метки классов;
- превращает отзыв в бинарный вектор слов;
- возвращает пару `(X, y)`.

Как работает векторизация:
- текст проходит через `preprocess_text`;
- каждое слово ищется в словаре;
- если слово встретилось, ставится `1` в соответствующую позицию.

То есть модель видит, какие слова есть в отзыве, но не видит их порядок.

### `ReviewClassifier`
Это тоже `MLP`.

Архитектура:
- `Linear(input_dim -> 256)`;
- `ReLU`;
- `Dropout(0.3)`;
- `Linear(256 -> 128)`;
- `ReLU`;
- `Linear(128 -> output_dim)`.

Смысл модели:
- по набору слов определить рейтинг отзыва.

После обучения:
- считается точность на тестовой выборке;
- проверяется работа модели на явно позитивном и явно негативном примерах.

## Термины

- `token` (токен) — элемент текста, с которым работает модель. В этой работе это либо символ, либо слово.
- `vocab` (словарь) — список всех известных токенов.
- `LabelEncoder` — преобразователь текстовых классов в числа.
- `DataLoader` — объект, который выдает данные батчами (`batch`, пакетами).
- `epoch` (эпоха) — один полный проход по обучающей выборке.
- `loss` (функция потерь, ошибка) — мера того, насколько сильно модель ошиблась.
- `CrossEntropyLoss` — стандартная функция потерь для многоклассовой классификации.
- `accuracy` — доля правильных предсказаний.
- `Dropout` — слой регуляризации (`regularization`, защита от переобучения), который случайно зануляет часть нейронов при обучении.

## Работа на GPU и очистка памяти

В ноутбуке по условию выставлено:
```python
device = torch.device("cuda:0")
```

Это означает, что вычисления направляются на нужную видеокарту.

После обучения каждой модели вызывается `clear_memory(...)`, внутри которой:
- удаляются ненужные объекты;
- вызывается `gc.collect()`;
- вызывается `torch.cuda.empty_cache()`.

Это сделано, чтобы память GPU очищалась перед следующим тяжелым блоком.
