# Объяснение решения

Основной файл с решением: `Текущий контроль 5-6/Задание.ipynb`.

## Что сделано

### 1. Fashion MNIST
- В `1.1` реализована классификация без сверточных слоев: используется `MLP` на полносвязных слоях.
- Считается количество обучаемых параметров модели.
- Модель обучается, строится график loss по эпохам.
- На тестовой выборке выводятся примеры предсказаний, матрица ошибок и accuracy.
- Веса сохраняются в `saved_models/fashion_mlp.pth`.
- В `1.2` реализована сверточная сеть для Fashion MNIST. После обучения также строятся метрики и визуализируются карты признаков первого сверточного слоя.

### 2. CIFAR-10
- В `2.1` реализована классификация без сверточных слоев: изображения нормализуются и подаются в `MLP`.
- В `2.2` реализована `CNN` для CIFAR-10.
- Для обеих моделей строятся графики потерь, матрицы ошибок, примеры предсказаний и считается accuracy.
- Веса сохраняются в `saved_models/`.

### 3. ImageFolder для внешних датасетов
- В `3.1` и `3.2` используется `torchvision.datasets.ImageFolder`.
- Добавлена функция `prepare_imagefolder_loaders`, которая делает `Resize`, аугментации, разбивку на train/test и создает `DataLoader`.
- Для обезьян и для кошек/собак реализованы отдельные `CNN`.
- Если каталогов с данными нет, ячейки не падают, а печатают, что каталог не найден.

### 4. Transfer Learning
- В `4.1` используется `VGG16` с предобученными весами для задачи с обезьянами.
- Показаны два режима: дообучение всей сети и дообучение только `classifier`.
- В `4.2` используется `ResNet18` для задачи cats vs dogs.
- Для transfer learning применяются `Resize(224, 224)` и нормализация `ImageNet`-статистиками.

## Как устроен код

В ноутбуке сначала идут общие функции:
- `count_parameters` считает число обучаемых параметров.
- `train_model` выполняет цикл обучения по эпохам.
- `evaluate_model` считает loss и accuracy на валидации/тесте.
- `plot_losses` строит график функции потерь.
- `show_predictions` показывает несколько изображений с правильными и предсказанными классами.
- `show_confusion` строит матрицу ошибок.
- `visualize_first_conv` визуализирует выходы первого сверточного слоя.

Это убирает дублирование кода между разделами.

## Что важно понимать

- `MLP` без сверток работает хуже на изображениях, потому что не использует пространственную структуру картинки.
- `CNN` лучше подходит для изображений, потому что свертки выделяют локальные признаки: контуры, текстуры, формы.
- `DataLoader` отвечает за батчи и перемешивание данных.
- `CrossEntropyLoss` используется для многоклассовой классификации.
- `accuracy` показывает долю правильных ответов.
- Матрица ошибок показывает, какие классы модель чаще всего путает.
- Transfer learning позволяет использовать уже обученные на `ImageNet` признаки и дообучать модель под новую задачу.

## Важное ограничение

Разделы `3.x` и `4.x` требуют наличия локальных папок:
- `data/monkeys`
- `data/cats_dogs`

Если их нет, ноутбук не упадет, но соответствующие ячейки не смогут обучить модель. Датасеты нужно предварительно скачать и распаковать в эти каталоги.
