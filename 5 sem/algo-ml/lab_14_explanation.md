# Объяснение лабораторной работы 14: Случайный лес для кредитного скоринга

## 1. Общая цель

Задача этой лабораторной работы — построить модель для **кредитного скоринга**, то есть предсказать вероятность того, что клиент банка не вернет кредит (совершит дефолт). Для этого используется одна из самых мощных и популярных моделей в машинном обучении — **Случайный лес (`RandomForestClassifier`)**.

## 2. Ключевые этапы и объяснение кода

### Шаг 1: Предобработка данных

Как и в предыдущей работе, данные требуют подготовки. В этом датасете также есть пропуски в столбцах `Income` (доход) и `NumDependents` (количество иждивенцев).

```python
train_df['Income'] = train_df['Income'].fillna(train_df['Income'].median())
```
Здесь, аналогично задаче с "Титаником", пропущенные значения заменяются **медианным** значением по столбцу. Это делается как для обучающей (`train_df`), так и для тестовой (`test_df`) выборок.

### Шаг 2: Настройка гиперпараметров с помощью `GridSearchCV`

Просто создать модель и обучить ее недостаточно. Чтобы получить максимальное качество, нужно подобрать для нее **гиперпараметры** — "настройки" алгоритма, которые задаются до начала обучения.

**Что такое Случайный лес (`RandomForestClassifier`)?**
Это **ансамбль** моделей. Он состоит из множества независимых друг от друга **Деревьев решений**. Каждое дерево обучается на случайной подвыборке данных и на случайном наборе признаков. Когда нужно сделать предсказание, каждое дерево "голосует", и финальным ответом становится тот класс, за который проголосовало большинство деревьев. Это позволяет значительно повысить точность и устойчивость модели к переобучению по сравнению с одним деревом.

**`GridSearchCV` (Поиск по сетке)**
Это инструмент для автоматического подбора лучших гиперпараметров. Вы задаете "сетку" (список) возможных значений для каждого гиперпараметра, а `GridSearchCV` перебирает все их комбинации, обучая и оценивая модель для каждой.

```python
forest_params = {'max_features': np.linspace(.3, 1, 7)}

locally_best_forest = GridSearchCV(
    RandomForestClassifier(n_estimators=100, random_state=17, n_jobs=-1),
    forest_params, scoring='roc_auc', cv=5
)
locally_best_forest.fit(X_train_split, y_train_split)
```
- `RandomForestClassifier` — модель, которую мы настраиваем. `n_estimators=100` — количество деревьев в лесу.
- `forest_params` — словарь с гиперпараметрами для перебора. В данном случае мы настраиваем `max_features` — долю признаков, которые может использовать каждое дерево.
- `scoring='roc_auc'` — метрика качества, по которой `GridSearchCV` будет выбирать лучшую модель. **ROC AUC** — отличная метрика для задач бинарной классификации, особенно с несбалансированными классами (когда клиентов, не вернувших кредит, гораздо меньше, чем тех, кто вернул). Она показывает, насколько хорошо модель умеет разделять классы.
- `cv=5` — **кросс-валидация** на 5 фолдах. Обучающие данные делятся на 5 частей. Модель 5 раз обучается на 4 частях и проверяется на 1 оставшейся. Результат усредняется. Это дает очень надежную оценку качества модели.

После выполнения `fit` в `locally_best_forest.best_params_` будут лежать лучшие найденные параметры.

### Шаг 3: Оценка модели на валидационной выборке

Как и в прошлой работе, мы используем **валидационную выборку**, чтобы честно оценить качество подобранной модели.

```python
valid_pred = locally_best_forest.predict(X_valid)
cm = confusion_matrix(y_valid, valid_pred)
```
Здесь мы делаем предсказания для отложенной части данных и строим **матрицу ошибок**, чтобы детально проанализировать, где модель ошибается. Мы также выводим `Accuracy`, чтобы иметь общее представление о доле верных ответов.

### Шаг 4: Важность признаков

Одно из преимуществ Случайного леса — возможность оценить **важность признаков (`feature_importances_`)**. Модель показывает, какой вклад внес каждый признак (возраст, доход и т.д.) в итоговый результат. Это очень полезно для анализа данных и понимания, что именно влияет на вероятность дефолта.

```python
feature_importances = pd.DataFrame(
    locally_best_forest.best_estimator_.feature_importances_,
    columns=['importance'],
    index=train_df.columns
).sort_values(by='importance', ascending=False)
```
Этот код извлекает значения важности, упаковывает их в удобную для чтения таблицу `pandas.DataFrame` и сортирует по убыванию.

### Шаг 5: Обучение финальной модели и предсказание

Наконец, мы создаем финальную, самую мощную модель.
- Мы используем лучшие параметры (`max_features`), найденные `GridSearchCV`.
- Мы увеличиваем количество деревьев до 300 (`n_estimators=300`), так как для Случайного леса "больше деревьев — лучше" (до определенного предела).
- **Важно:** финальная модель обучается на **всех** доступных обучающих данных (`train_df`), чтобы использовать максимум информации.

```python
final_forest = RandomForestClassifier(
    n_estimators=300,
    max_features=locally_best_forest.best_params_['max_features'],
    # ... другие параметры
)
final_forest.fit(train_df, y)
final_forest_pred = final_forest.predict_proba(test_df)[:, 1]
```
- `predict_proba(test_df)[:, 1]` — этот метод делает предсказание **вероятностей**. В задаче кредитного скоринга нам важна не просто метка "вернет/не вернет", а именно вероятность дефолта. `[:, 1]` выбирает вероятности, относящиеся к классу "1" (дефолт).
- Полученный прогноз сохраняется в файл для отправки на соревнование.
