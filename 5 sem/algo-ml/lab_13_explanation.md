# Объяснение лабораторной работы 13: Дерево решений для задачи "Титаника"

## 1. Общая цель

Основная задача этой лабораторной работы — построить модель машинного обучения, которая предсказывает, выживет ли пассажир "Титаника" на основе его данных (класс каюты, пол, возраст и т.д.). В качестве модели используется **Дерево решений (`DecisionTreeClassifier`)**.

## 2. Ключевые этапы и объяснение кода

### Шаг 1: Предобработка данных

Прежде чем обучать модель, сырые данные необходимо подготовить. Это один из самых важных этапов в машинном обучении.

**Проблемы в данных:**
- **Пропуски (NaN):** В данных о пассажирах есть пропущенные значения (например, не у всех указан возраст). Модели не могут работать с пропусками, их нужно обработать.
- **Категориальные признаки:** Признаки вроде "Пол" (`Sex`) или "Порт посадки" (`Embarked`) являются текстовыми. Модели машинного обучения работают с числами, поэтому текст нужно преобразовать.

**Как это решается в коде:**
1.  **Заполнение пропусков:**
    ```python
    train_df['Age'] = train_df['Age'].fillna(train_df['Age'].median())
    ```
    Здесь мы заменяем все пропущенные значения в столбце `Age` на **медиану** (серединное значение) по этому же столбцу. Это простой и распространенный способ "залатать дыры" в данных.

2.  **Преобразование категориальных признаков в числовые:**
    ```python
    train_df = pd.concat([train_df, pd.get_dummies(train_df['Sex'], prefix="Sex")], axis=1)
    ```
    Для этого используется метод **One-Hot Encoding** (в `pandas` это функция `get_dummies`). Он создает новые столбцы для каждого уникального значения в категориальном признаке. Например, столбец `Sex` с значениями `male` и `female` превратится в два новых столбца: `Sex_male` и `Sex_female`, где `1` означает присутствие признака, а `0` — отсутствие. Это позволяет модели работать с этими данными.

3.  **Удаление ненужных признаков:**
    ```python
    train_df.drop(['Name', 'Ticket', 'Cabin'], axis=1, inplace=True)
    ```
    Признаки вроде имени пассажира, номера билета или номера каюты, скорее всего, не несут полезной информации для предсказания выживаемости и могут только "запутать" модель. Поэтому их удаляют.

### Шаг 2: Обучение Дерева Решений

**Что такое Дерево Решений?**
Это модель, которая делает предсказания, задавая последовательность простых вопросов о данных. Например: "Пол пассажира — женский?", "Возраст — меньше 10 лет?". Каждый вопрос делит данные на группы, и так продолжается до тех пор, пока в конечных группах (листьях дерева) не окажутся пассажиры с одним и тем же исходом (выжил/погиб).

```python
tree = DecisionTreeClassifier(max_depth=2, random_state=17)
tree.fit(train_df, y)
```
- `DecisionTreeClassifier` — это класс дерева решений для задач классификации в `scikit-learn`.
- `max_depth=2` — это **гиперпараметр**, который ограничивает глубину дерева двумя уровнями вопросов. Это очень важный параметр для **борьбы с переобучением**. Без ограничения дерево может стать слишком сложным, выучить все детали обучающих данных (включая шум) и будет плохо работать на новых, невиданных ранее данных.
- `random_state=17` — используется для воспроизводимости результатов. Гарантирует, что при каждом запуске кода дерево будет строиться одинаково.
- `tree.fit(train_df, y)` — это процесс **обучения** модели, где `train_df` — это подготовленные признаки, а `y` — это целевая переменная (столбец `Survived`, который мы хотим предсказать).

### Шаг 3: Оценка качества модели

Чтобы понять, насколько хорошо работает наша модель, ее нужно оценить. Нельзя оценивать модель на тех же данных, на которых она обучалась, так как она может просто "запомнить" правильные ответы.

**Валидационная выборка**
Для корректной оценки обучающие данные делятся на две части:
- **Обучающая выборка (`train_split`):** На ней модель учится.
- **Валидационная выборка (`valid`):** Это "экзамен" для модели. Она не видела эти данные во время обучения. Мы делаем предсказания для этой выборки и сравниваем их с реальными ответами.

```python
X_train_split, X_valid, y_train_split, y_valid = train_test_split(X, y, test_size=0.3, random_state=17)
```
- `train_test_split` — функция, которая делит данные.
- `test_size=0.3` — означает, что 30% данных уйдет в валидационную выборку.

**Метрики качества**
1.  **Accuracy (Точность):**
    ```python
    accuracy_score(y_valid, valid_pred)
    ```
    Это самая простая метрика, которая показывает **долю правильных ответов** от общего числа предсказаний.

2.  **Матрица ошибок (`confusion_matrix`):**
    Это таблица, которая наглядно показывает, где именно модель ошибается.
    - **True Positive (TP):** Модель правильно предсказала "выжил".
    - **True Negative (TN):** Модель правильно предсказала "погиб".
    - **False Positive (FP):** Модель предсказала "выжил", но на самом деле пассажир погиб (ошибка I рода).
    - **False Negative (FN):** Модель предсказала "погиб", но на самом деле пассажир выжил (ошибка II рода).

    Матрица ошибок дает гораздо больше информации, чем просто `Accuracy`, особенно в задачах с несбалансированными классами.

### Шаг 4: Финальный прогноз
После того как мы оценили модель и убедились в ее качестве, для финального предсказания на тестовых данных (где нет ответов) модель обучают заново, но уже **на всех доступных обучающих данных**. Это делается для того, чтобы модель использовала максимум информации перед тем, как делать прогноз на реальных данных.
