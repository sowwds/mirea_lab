## 2. Ключевые концепции и объяснение кода

### Что такое SVM?

Основная идея SVM — найти **гиперплоскость** (в двумерном случае — просто линию), которая наилучшим образом разделяет классы. "Наилучшим образом" означает, что зазор (margin) между этой плоскостью и ближайшими точками каждого класса (опорными векторами) должен быть максимальным. Это делает модель устойчивой и хорошо обобщающей.

### Шаг 1: Классификация с `SVC`

#### Масштабирование данных
```python
scaler_clf = StandardScaler()
X_clf_train_scaled = scaler_clf.fit_transform(X_clf_train)
```
**Масштабирование (или нормализация) данных — критически важный шаг для SVM.** Алгоритм очень чувствителен к масштабу признаков. Если один признак измеряется в тысячах, а другой — в долях единицы, SVM будет считать первый признак гораздо более важным. `StandardScaler` приводит все признаки к одному масштабу (с нулевым средним и единичной дисперсией), что позволяет модели адекватно их оценивать.

#### Ядерный трюк (Kernel Trick)
Что делать, если данные нельзя разделить прямой линией? SVM использует **ядерный трюк**. Идея в том, чтобы перевести данные в пространство более высокой размерности, где их, возможно, удастся разделить гиперплоскостью.

**Основные типы ядер (`kernel`):**
- `linear`: Линейное ядро. Используется, когда данные уже линейно разделимы.
- `poly`: Полиномиальное ядро. Строит разделяющую поверхность в виде полинома.
- `rbf`: Радиальная базисная функция. Одно из самых популярных и мощных ядер. Может справляться с очень сложными границами.

#### Подбор гиперпараметров
Мы снова используем `GridSearchCV` для поиска лучшей комбинации ядра и других гиперпараметров.
- `C`: Параметр регуляризации. Отвечает за баланс между "гладкостью" разделяющей поверхности и правильностью классификации обучающих точек.
  - **Маленький `C`**: Широкий зазор, модель более "простая", допускает ошибки на обучающей выборке.
  - **Большой `C`**: Узкий зазор, модель стремится правильно классифицировать все точки, что может привести к переобучению.
- `gamma`: Параметр ядра `rbf`. Определяет, насколько "далеко" влияет одна обучающая точка.
- `degree`: Степень полинома для ядра `poly`.

```python
param_grid = [
    {'C': [0.1, 1, 10], 'kernel': ['linear']},
    {'C': [0.1, 1, 10], 'kernel': ['rbf'], 'gamma': ['scale', 0.1]},
    # ... и т.д.
]
grid_search_clf = GridSearchCV(SVC(), param_grid, cv=5)
grid_search_clf.fit(X_clf_train_scaled, y_clf_train)
```
Код перебирает разные ядра и их параметры, чтобы найти наилучшую модель.

### Шаг 2: Регрессия с `SVR`

Для задачи регрессии (предсказание непрерывной величины) используется `SVR` (Support Vector Regression). Идея похожа, но вместо поиска максимального зазора между классами, SVR пытается построить "трубку" (коридор) заданной ширины, внутри которой должно оказаться как можно больше точек.

Код для `SVR` аналогичен `SVC`: мы также масштабируем данные, используем `GridSearchCV` для подбора ядра и параметра `C`, а затем визуализируем результат, накладывая предсказания модели на реальные данные.

### Шаг 3: Сравнение с другими методами

Это важный этап, который показывает, что не существует "универсально лучшего" алгоритма. Для конкретной задачи один метод может работать лучше другого.

```python
dt_clf = DecisionTreeClassifier()
rf_clf = RandomForestClassifier()
# ... обучение и предсказания
print(classification_report(y_test, y_pred_svm))
print(classification_report(y_test, y_pred_dt))
print(classification_report(y_test, y_pred_rf))
```
Здесь мы на тех же данных обучаем **Дерево Решений** и **Случайный Лес**, а затем сравниваем их метрики с метриками лучшей модели SVM. `classification_report` предоставляет детальную информацию, включая:
- **Precision (Точность):** Доля объектов, действительно принадлежащих классу, среди всех объектов, которые модель отнесла к этому классу.
- **Recall (Полнота):** Доля объектов, которые модель правильно отнесла к классу, среди всех реальных объектов этого класса.
- **F1-score:** Среднее гармоническое между точностью и полнотой, обобщающая метрика.

Такое сравнение позволяет сделать обоснованный вывод о том, какая модель лучше подходит для решения поставленной задачи.
