## 1. Общая цель

Цель работы — применить **наивный байесовский классификатор** для решения задачи классификации на примере классического датасета **ирисов Фишера**. Работа включает в себя обучение модели, оценку ее точности и визуализацию результатов.

## 2. Ключевые концепции и объяснение кода

### Что такое Наивный Байесовский Классификатор?

Это вероятностный классификатор, работающий на основе **теоремы Байеса**.

**Теорема Байеса:**
$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$

В контексте машинного обучения это можно записать как:
$P(\text{класс}|\text{признаки}) = \frac{P(\text{признаки}|\text{класс}) \cdot P(\text{класс})}{P(\text{признаки})}$

- $P(\text{класс}|\text{признаки})$ — **апостериорная вероятность**: вероятность того, что объект относится к определенному классу, при известных его признаках. Это то, что мы хотим найти.
- $P(\text{признаки}|\text{класс})$ — **правдоподобие**: вероятность встретить такие признаки у объекта, если он принадлежит данному классу.
- $P(\text{класс})$ — **априорная вероятность**: как часто в целом встречается этот класс в данных.
- $P(\text{признаки})$ — полная вероятность признаков (выступает как нормализующий множитель).

**"Наивное" предположение:**
Главное упрощение, которое делает этот алгоритм — он предполагает, что все **признаки независимы** друг от друга. Например, для ирисов это означает, что длина лепестка никак не связана с его шириной. В реальности это почти всегда не так, но это "наивное" предположение сильно упрощает вычисления и, на удивление, часто дает хорошие результаты.

### Шаг 1: Загрузка и подготовка данных

```python
from sklearn.datasets import load_iris
```

- `X = iris.data[:, :2]`: Мы берем только первые два признака (длину и ширину чашелистика), чтобы можно было легко визуализировать результат на 2D-графике.
- `y = iris.target`: Это целевая переменная — вид ириса (0 - setosa, 1 - versicolor, 2 - virginica).

### Шаг 2: Обучение `GaussianNB`

Существуют разные типы наивных байесовских классификаторов, которые отличаются предположениями о распределении признаков.

**`GaussianNB` (Гауссовский Наивный Байес):**
Этот вариант используется, когда признаки являются **непрерывными вещественными числами** (как длина и ширина лепестков). Он предполагает, что признаки для каждого класса распределены по **закону Гаусса (нормальному распределению)**.

```python
from sklearn.naive_bayes import GaussianNB

gnb = GaussianNB()
gnb.fit(X_train, y_train)
```
- **Восстановление плотности:** Процесс `fit` в данном случае и есть "восстановление плотности". Модель не строит сложную функцию, а просто вычисляет **среднее значение** и **дисперсию** для каждого признака (`sepal length`, `sepal width`) в контексте каждого из трех классов ирисов. Эти параметры (среднее и дисперсия) полностью описывают гауссову кривую плотности вероятности для каждого признака.
- Когда приходит новый, неизвестный ирис, модель для каждого из трех классов рассчитывает, насколько вероятно было бы получить такие значения длины и ширины чашелистика, если бы этот ирис принадлежал к данному классу.
- Класс с наибольшей итоговой вероятностью и становится предсказанием.

После обучения модели на `X_train`, мы делаем предсказания для `X_test` и сравниваем их с реальными метками `y_test`.

    ```python
    print(f"Точность: {accuracy_score(y_test, y_pred):.4f}")
    print(classification_report(y_test, y_pred))
    ```
    Мы выводим `accuracy` (долю правильных ответов) и `classification_report` (precision, recall, f1-score), чтобы получить полное представление о качестве классификации для каждого класса.

2.  **Визуализация:**
    ```python
    from mlxtend.plotting import plot_decision_regions

    plot_decision_regions(X_test, y_test, clf=gnb)
    ```
    Это самый наглядный этап. Функция `plot_decision_regions` рисует график, на котором:
    - Точками показаны реальные данные из тестовой выборки.
    - Фонов залиты области, соответствующие предсказаниям модели.

    Этот график наглядно показывает, какие "границы" модель провела между классами на основе вычисленных вероятностных распределений. Мы можем визуально оценить, где модель работает хорошо, а где допускает ошибки.
