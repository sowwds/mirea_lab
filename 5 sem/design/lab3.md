# Лабораторная работа №3: Информационная архитектура

## Структура сайта "Serenity AI"

Ниже представлена иерархическая структура разделов сайта, разработанная на основе информации о компании "Serenity AI".

*   **Главная страница (Лендинг)**
    *   **О сервисе**
        *   Как это работает (описание технологии ИИ)
        *   Наша миссия и ценности
        *   Гарантии безопасности и анонимности
    *   **Возможности**
        *   Чат с ИИ-психологом (начало диалога)
        *   Аналитика состояния (дашборд пользователя)
        *   Дневник эмоций
    *   **Тарифы**
        *   Сравнение планов (бесплатный, премиум)
        *   Оформить подписку
    *   **FAQ (Частые вопросы)**
    *   **Старт**
        *   *Действие: Регистрация / Вход*
        *   *Действие: Попробовать бесплатно*
    *   **Контакты**
        *   Соцсети
        *   Адрес

## Схема в формате PlantUML

Код ниже можно использовать для генерации диаграммы информационной архитектуры сайта "Serenity AI" с помощью PlantUML.

```plantuml
@startuml
@startmindmap
+ Главная страница
++ О сервисе
+++ Как это работает
+++ Наша миссия и ценности
+++ Безопасность и анонимность
++ Возможности
+++ Чат с ИИ-психологом
+++ Аналитика состояния
+++ Дневник эмоций
++ Тарифы
+++ Сравнение планов
+++ Оформить подписку
++ FAQ
++ Старт
+++ Регистрация / Вход
+++ Попробовать бесплатно
++Контакты
+++Соцсети
+++Адрес
@endmindmap
@enduml

```
